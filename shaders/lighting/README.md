# `shaders/lighting/`

Reconstructed HLSL reference for FO4's deferred lighting pipeline.

This directory is a **reference**, not a runtime asset. Files here are
human-readable reconstructions of Bethesda's precompiled `.fxp` shaders
intended to inform feature implementations elsewhere in the repo.

The `lighting-shader-id-map.json` companion file is auto-generated by
`Fallout4RE/Workspace/tools/commands/build-lighting-shader-id-map.py` and
should be regenerated whenever `Fallout4RE/exports/cs-render-subsystem-ids.json`
changes.

## Workflow

The reconstruction pipeline is documented in
`Fallout4RE/Workspace/docs/lighting-shader-reconstruction-runbook.md`.
At a high level:

1. **Mechanical stage** (automated, no judgement required):
   * Capture a frame in RenderDoc (use the in-game `RenderDoc` feature
     plugin), OR extract `Data/Fallout4 - Shaders.ba2` with BSArchPro.
   * Run `python Fallout4RE/Workspace/tools/commands/disassemble-dxbc.py
     <container>` on each shader binary; this writes
     `<name>.<index>.<sha1>.dxbc.asm` files plus JSON sidecars.
2. **Manual stage** (per-shader; honest reconstruction):
   * For each target asm, identify CB layout, texture slots, and BRDF
     shape. Use `// TODO: identify` rather than guessing.
   * Cross-check by recompiling the reconstruction with `dxc.exe` and
     diffing the resulting DXBC against the original ASM.

The runbook bars speculation: any HLSL committed here is expected to
either (a) round-trip to ASM that closely matches the original bytecode,
or (b) be marked WIP with explicit `// TODO` blocks.

## Why these three first

Phase A targets are chosen so that delivering them unblocks SSGI Phase 2
in the sibling integration: the ambient/IBL pass tells us how the engine
applies AO to the ambient term, so the SSGI feature can integrate at the
right boundary instead of post-modulating `kDiffuseBuffer` (which
darkens direct light along with ambient).

Phase B (point/spot lights, shadow application, fog, material
permutations) is gated on Phase A delivering at least one verified
reconstruction.
